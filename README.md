## How I work

- **Useful first** — 先完成能解决具体问题的端到端版本。
- **Evidence over claims** — 用测试、CI、复现步骤和发布记录说明质量。
- **Privacy by design** — 能在本地完成的处理，不依赖账号、云端或长期凭据。
- **Open collaboration** — 欢迎通过项目 Issue 提交问题、建议或使用场景。
